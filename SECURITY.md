# Reportar vulnerabilidades

Não publique tokens, credenciais ou detalhes exploráveis em uma issue pública.

Use um GitHub Security Advisory privado neste repositório. Se o recurso não estiver disponível, contate o proprietário do repositório pelo perfil do GitHub e peça um canal privado para o relato. Inclua passos para reproduzir, impacto, versões afetadas e uma forma segura de retorno.

O painel deve permanecer em loopback e ser acessado remotamente por VPN/rede privada e SSH. Não compartilhe o token administrativo em relatórios públicos.
